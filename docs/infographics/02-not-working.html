Same stack: what is not working

These are measured gaps, not guesses. The 20 mm pinch-and-lift can succeed and still fail the items below.

1. Cube is never let go

After a hold, run_dn_bus.py finally applies preset Folded (gripper 0 mm) while the cube is still attached.

Last eval-size20 tick 36: attached true, gripper 20.02 mm. Grasp only releases if opening ≥ cube width + 12 mm. Folded closes, so the cube stays in the jaws.

2. Moved cube is not followed

Approach, hold_pad_dx, and hold_pad_dy aim at CLI args.x / args.y (default 280 mm, 0 mm), not live objects.cube.center_mm.

If you drag the cube in the simulator after spawn, the bus still rails to the spawn XY. It will not pick the new place.

3. Dopamine is not learned

Episode flag da_learned is false. No freeze / shuffle / erase of KC→MBON that changed pick or abort rate.

Plan: PAM-like / PPL1-like pulse on existing KC→MBON at trial end. That ablation has not been shown.

4. Leg motor neurons do not steer

T1 vnc_motor mean Hz is logged (last episode ~689 Hz). It is not mapped to TCP or joints.

The B601 unpacker is lab IK. Putting T1 MN rates on the joystick is the wrong plant for this LIF.

5. Jaws do not open after the pinch

U still emits negative dgrip after attach (~−7.9 mm). grip_target_mm floors at cube width (20 mm), so the gripper never opens during the episode.

Release is not in the distilled map. Cleanup never opens to 90 mm before Folded.

6. Not the full fly, not a moved-cube policy

Live plant is a 59,740-cell crop, not all ~166k MaleCNS neurons. Overlay / k-NN / quintic are teacher and do not count as fly_picked.

keep_level cannot pinch a 20 mm table cube: link5 hits the floor below ~42 mm TCP. Fingertips-down is required. That is geometry, not vision.

What a passing “let go + moved cube” test would require

  1. After hold ≥ 2 s, open ≥ 32 mm (20 mm cube + 12 mm release) so Grasp detaches; cube falls. Then Folded.
  2. Each tick, read live cube XY from state and aim pads there — not frozen args.x, args.y.
  3. Retrain distill on those traces. Do not score overlay or |dz| as fly.
